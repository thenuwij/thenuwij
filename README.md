## Hi, I'm Thenuja 👋

I'm a Computer Engineering (Honours) graduate from UNSW Sydney, now a Research Assistant there. I work on backend systems and applied AI, and lately I've been focused on reliability: building services that keep working when parts of them fail, and running them in production.

My most recent project is **[Recall](https://github.com/thenuwij/recall)**, a study tool written in Go that turns your notes into practice questions and schedules reviews with spaced repetition. Most of the interesting work is underneath: background jobs that survive worker crashes and Redis outages, tests that deliberately break things to prove no job is lost or duplicated, and a deployment on AWS with nightly backups and a tested restore. It's live at [recall.thenujawijesuriya.com](https://recall.thenujawijesuriya.com) if you want to try it.

For my Honours thesis I built **[UniVise](https://github.com/thenuwij/UniVise)**, a full-stack platform that helps university students plan courses, majors, and career pathways. I focused mainly on the backend logic and AI integration, using Python, FastAPI, PostgreSQL and React. It's deployed on AWS and now university-funded, so I maintain it for its student test users, with a usability study coming up. It received a High Distinction and a spot in the UNSW CSE Thesis Showcase 2025.

On the machine learning side, I've trained computer vision models in PyTorch, including [crop pest detection with YOLOv8s](https://github.com/thenuwij/agropest-12-yolov8) and facial emotion recognition with ResNet-34. During a backend internship, I built service-health monitoring APIs on Azure.

Closer to the hardware, one of my favourite things I've built is still a [real-time FPGA audio pipeline](https://github.com/thenuwij/FPGA-Audio-Pipeline) in VHDL using AXI DMA.
